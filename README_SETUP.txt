مرحباً بك! منصة "مستشارك القانوني" هي بيئة برمجية متكاملة لتقديم الاستشارات
القانونية الذكية وفحص العقود وإدارة ملفات الدعاوي القضائية وفقاً للتشريعات
المصرية وأحكام محكمة النقض.

--------------------------------------------------------------------------------
1. البنية المعمارية للمشروع (Architecture Overview):
--------------------------------------------------------------------------------
src/law/
  ├── index.tsx: المدخل الرئيسي والواجهة الجامعة لكافة التبويبات والتنقلات.
  ├── types/index.ts: كافة النماذج والتعريفات البرمجية الصارمة (TypeScript).
  ├── utils/legalAgentEngine.ts: محرك التحليل القانوني الذكي، وفحص العقود، وحساب نسب اكتمال الدعاوى.
  ├── data/
  │    ├── egyptianLegalCodexFull.ts: نصوص القوانين المصرية (المدني، العقوبات، الأسرة، العمل، إلخ).
  │    ├── egyptianLegalKnowledge.ts: الثغرات والدفوع وحلول الأفخاخ القانونية ومواعيد التقادم.
  │    └── lawyersData.ts: قائمة المحامين المعتمدين مع الإحداثيات وحساب المسافات الجغرافية.
  └── components/
       ├── LegalAIAgentChat.tsx: المساعد الذكي الآلي الفوري مع الاستشهاد بنصوص القانون.
       ├── CaseFileBuilder.tsx: صانع ملف القضية وحساب مؤشر الجاهزية وطباعة التقرير.
       ├── CaseTypeSelector.tsx: منتقي الدوائر والتخصصات القضائية.
       ├── DocumentAnalyzer.tsx: فاحص العقود والمستندات لكشف الثغرات والبنود الخطرة.
       ├── EgyptianCodexViewer.tsx: الباحث في الموسوعة التشريعية برقم المادة والكلمة.
       ├── LawyersDirectory.tsx: دليل المحامين مع الفرز بالمحافظة والتخصص والمسافة.
       ├── LawyerProfilePage.tsx: الملف التعريفي الكامل للمحامي وتقييماته وساعات العمل.
       ├── ConsultationBookingModal.tsx: نافذة حجز الاستشارات واختيار الطريقة وتوليد الكود.
       ├── LawyerDashboard.tsx: لوحة تحكم المحامي لاستقبال ومراجعة ملفات الموكلين.
       └── AdminGatewayPanel.tsx: لوحة بوابة الـ API لتوليد المفاتيح واختبار الـ Endpoints.

server/
  └── lawGatewayRoutes.ts: مسارات الـ REST API لبوابة الاستعلامات وفحص العقود والتحقق من التراخيص.

public/law/
  └── widget.js: الودجت العائم للتضمين بسطر كود واحد في أي موقع ويب.

--------------------------------------------------------------------------------
2. متطلبات التشغيل (Prerequisites):
--------------------------------------------------------------------------------
- Node.js إصدار 18 فما فوق (أو 20 LTS)
- مدير الحزم npm أو bun أو pnpm

--------------------------------------------------------------------------------
3. خطوات التثبيت والتشغيل السريع (Quickstart):
--------------------------------------------------------------------------------
أ) تثبيت الاعتماديات:
   npm install

ب) التشغيل في بيئة التطوير (Development Mode):
   npm run dev
   - سيعمل التطبيق على المنفذ: http://localhost:3000

ج) بناء المشروع للإنتاج (Production Build):
   npm run build
   npm run preview (أو npm start في حال تشغيل خادم Express)

--------------------------------------------------------------------------------
4. تضمين الودجت العائم في أي موقع ويب (Embed Widget):
--------------------------------------------------------------------------------
لإضافة المساعد القانوني الفوري في أي موقع ويب خارجي، ضع هذا السطر فقط قبل وسم </body>:

<script 
  src="https://your-domain.com/law/widget.js" 
  data-api-key="law_live_mst_YOUR_KEY"
  data-theme="dark"
  data-position="bottom-left"
  async>
</script>

--------------------------------------------------------------------------------
5. نقاط نهاية بوابة الـ REST API المتاحة (Endpoints):
--------------------------------------------------------------------------------
- POST /api/law/chat: استشارة قانونية فورية وتحديد نصوص المواد
- POST /api/law/analyze-contract: تحليل وفحص نصوص العقود وكشف الثغرات
- GET  /api/law/codex/search?q=341: البحث في الموسوعة التشريعية
- GET  /api/law/lawyers?gov=القاهرة: دليل المحامين والفرز الجغرافي
- POST /api/law/case-file: توليد ملف الدعوى واحتساب الجاهزية
